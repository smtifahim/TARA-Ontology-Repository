TARA Ontology Browsers & Tools

Generated, interactive tools for the ontologies in the TARA Ontology repository.

  • TARA Acupoints Ontology Explorer Acupoints hierarchies, Pinyin/Chinese labels and synonyms, and Topographical Anatomy (surface location, related nerves and vasculature) linked to imported UBERON/ILX terms. Searching an anatomical entity lists the acupoints located within it.
  • TARA Standard Articles Metadata Core Metadata schema for acupuncture clinical trial publications: classes, annotation properties, domain/range, the OCSI scoring hierarchy, and the per-field LLM extraction prompts.
  • TARA Acupoints Innervation Pathways Axonal pathways of the SCKAN neurons whose course (ilxtr:hasAxonLocation) runs through an acupoint's related nerves, drawn from soma → axon → axon terminal into a collapsed target-organ node. Search by acupoint, meridian, related nerve, mapping neuron, phenotype, or target organ.
