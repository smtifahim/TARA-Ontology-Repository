TARA Ontology Browsers

Generated, interactive browsers for the ontologies in this repository.

  • TARA Acupoints Ontology The Acupoints Ontology: Acupoints hierarchies, Pinyin/Chinese labels and synonyms, and Topographical Anatomy (surface location, related nerves and vasculature) linked to imported UBERON/ILX terms. Searching an anatomical entity lists the acupoints located within it.
  • TARA Standard Articles Metadata Core Ontology Metadata schema for acupuncture clinical trial publications: classes, annotation properties, domain/range, the OCSI scoring hierarchy, and the per-field LLM extraction prompts.
